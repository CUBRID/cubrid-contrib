# Code formatting for CUBRID

'Autoformat on Save' support for CUBRID

## Plans for Support

### Supported Languages

- [x] c / cpp
- [ ] cmake
- [ ] bash
- [ ] java

> NOTE: c/cpp is set by raw filename extension,
not by the actual file type set by CMake properties.
This is due to the limitation of the current GitHub Actions CI setup of CUBRID.

### Supported Editors and IDEs

- [x] Neovim
- [x] VS Code
- [ ] CLion
